# DMZ Love Letter

Inoffizieller interaktiver Fan-Cartoon zu Call of Duty: DMZ.

Nicht mit Activision verbunden. Keine Datenerhebung, keine Cookies, keine externen Anfragen. Der Browser merkt sich lokal nur die Bilddrehung am Handy.

Alles steckt in einer einzigen Datei: `index.html`.

Bedienung: Leertaste = Pause, Pfeile = spulen, C = Chaos, M = Ton. Am Handy einfach tippen.
